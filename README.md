# coginterp.github.io/iclr2027/ 

Website for the Second Workshop on Interpreting Cognition in Deep Learning Models, proposed for ICLR 2027

Previous edition: https://coginterp.github.io/neurips2025/ (NeurIPS 2025)



Template adopted from: https://github.com/MRL-Workshop/iclr-2023



To host the website locally, after cloning this repo run `hugo server` in the main directory
